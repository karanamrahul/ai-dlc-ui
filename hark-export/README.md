# Hark export — Wi-Fi Patch QA

Offline package of the Hark storyboard:

https://hark.com/site/eea040f8-f57a-4193-8688-f0470b20198d?hark_region=us

## Browse

Open `index.html` for the screenshot gallery, or read `CONTENT.md`.

Hark is WebGL-only in-browser; this export is screenshots + transcribed structure, not a runnable clone of Hark’s engine.

## Layout

```
index.html          screenshot gallery
CONTENT.md          transcribed storyboard
README.md           this file
screenshots/        full captures (tabs, scenarios, scroll)
export/             meta + asset manifest
assets/             fetched Hark JS/CSS/JSON (partial; no WebGL runtime)
```
